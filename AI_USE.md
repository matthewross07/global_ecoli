# Use of AI-assisted coding tools

Code in this repository — for cleaning, analysis, and figure generation — was
drafted with AI assistance, using Claude Code (Anthropic). The study design,
data source selection, harmonization and quality-control rules, analytical
definitions, and interpretation were determined by the authors. Every reported
quantity is regenerated by an archived script from the archived dataset
(`paper_stats/README.md` maps each number to the script that produces it), and
the archived compute capsule reproduces all figures and tables. The authors take
full responsibility for the content of this repository, including all code and
results.

This is the repository-level counterpart to the disclosure in the manuscript's
Methods section. The acquisition and harmonization half of the work lives in the
`wqual_pipeline` repository, which carries its own statement.
